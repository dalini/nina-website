## Requirement

- **Statement**: The Site Build MUST generate every public page in German and in English, each rendering the language's value of every bilingual field, and every page MUST show a language switch that opens the same page in the other language.
- **Rationale**: The audience is international; every page exists in both languages (FR-1.2) and visitors switch without losing their place (FR-1.3).
- **Assumptions**: None
- **Out of Scope**: Default language for visitors who have not chosen one, including what the site root shows (FR-1.6, blocked by PQ-8); behavior when one language value is empty (FR-1.7, blocked by PQ-9); remembering the choice in the browser (no requirement; would need client-side code, AQ-2).
- **Design Traceability**: DESIGN.md Components (Language switch: "DE | EN" in the header, current language marked and announced to screen readers; Focus state); DESIGN.md Accessibility (WCAG 2.2 AA, visible focus, keyboard use, `lang`); `style-guide.html` as the rendered reference
- **Architecture Traceability**: Site Build (generates all pages in DE and EN and the language switch targets); Public Site; DR-3
- **Security Traceability**: SEC-OUT-1 (rendering via REQ-OUTPUT-010); SEC-OUT-5 applies only if client-side code is added (AQ-2)

## Acceptance Criteria

1. **AC-01 — Expected behavior**: Given a Text with German and English values, when the Site Build runs, then a German page shows the German values, an English page shows the English values, and each page's `lang` attribute is `de` or `en` respectively.
2. **AC-02 — Expected behavior**: Given any generated page, when the visitor activates the language switch, then the browser opens the same page in the other language.
3. **AC-03 — Boundary or failure behavior**: Given a Work whose title is lowercase, when both language pages are generated, then both show the identical title as entered (FR-1.5).
4. **AC-04 — Additional criterion**: Given a keyboard-only visitor or a screen reader, when the language switch is reached, then it is focusable with a visible 2 px outline, shows "DE | EN", and the current language is marked and announced.
5. **AC-05 — Prohibited behavior**: Given any generated page, when its switch target is followed, then it never leads to a missing page or to a different content item.
