## Acceptance Criteria

1. **AC-01 — Expected behavior**: Given any generated page in either language, when it is opened, then it shows links to Works, Exhibitions/News, Texts, CV and Contact in that language's version of the site.
2. **AC-02 — Boundary or failure behavior**: Given the visitor is on the CV page, when the navigation is shown, then only the CV link carries the current-page marking.
3. **AC-03 — Prohibited behavior**: Given any navigation link, when it is followed, then it never leads to a sign-in, a 404 or the other language.
4. **AC-04 — Additional criterion**: Given a keyboard user, when tabbing through the header, then every navigation link is reachable and shows the focus outline.
