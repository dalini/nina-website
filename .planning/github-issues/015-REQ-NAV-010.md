## Requirement

- **Statement**: Every public page MUST show navigation links to Works, Exhibitions/News, Texts, CV and Contact in the page's language, and every linked page MUST be reachable without logging in.
- **Rationale**: Visitors move between the main sections from any page (FR-1.1) without an account (NFR-2).
- **Assumptions**: None
- **Out of Scope**: The Exhibitions/News page itself (FR-4, blocked by PQ-11): the link is present and its target is verified once that page exists; the header mark or wordmark (DESIGN.md DQ-2, PQ-25).
- **Design Traceability**: DESIGN.md Components (Links: navigation shows the current page with a 2 px bottom border; Focus state); Layout and Spacing (breakpoints); DESIGN.md Accessibility (WCAG 2.2 AA, visible focus, keyboard use, `lang`); `style-guide.html` as the rendered reference
- **Architecture Traceability**: Site Build (all pages); Public Site

## Acceptance Criteria

1. **AC-01 — Expected behavior**: Given any generated page in German or English, when it is loaded, then it shows five navigation links (Works, Exhibitions/News, Texts, CV, Contact) labeled in the page's language, each pointing to that section in the same language.
2. **AC-02 — Expected behavior**: Given the visitor is on a section page, when the navigation is shown, then that section's link is marked as current with a 2 px bottom border and is announced as current to screen readers.
3. **AC-03 — Boundary or failure behavior**: Given a viewport of 320 px width and a keyboard-only visitor, when the navigation is used, then every link is reachable and operable by keyboard with a visible focus outline.
4. **AC-04 — Prohibited behavior**: Given any navigation target, when it is requested without credentials, then it is served without a login prompt or account requirement.
