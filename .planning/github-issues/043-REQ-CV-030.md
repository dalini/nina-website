## Acceptance Criteria

1. **AC-01 — Expected behavior**: Given a past group entry with a CV wording override in German and English, when the CV is generated, then the line shows the override in each language.
2. **AC-02 — Boundary or failure behavior**: Given a public-space work marked hidden from the CV, when the CV is generated, then no line for it appears and the work page is unchanged.
3. **AC-03 — Prohibited behavior**: Given an override, when the CV is generated, then the generated wording does not appear in addition to it.
