## Requirement

- **Statement**: The CV page MUST show short bio, education, solo exhibitions, works in public space, group exhibitions, and awards and grants, each as its own section containing the published CV entries of that section.
- **Rationale**: Curators and press read the CV by category (FR-5.2).
- **Assumptions**: None
- **Out of Scope**: Deriving CV sections from Exhibition entries or public-space works (not in the sources; PQ-23); ordering of entries in a section (PQ-19).
- **Design Traceability**: DESIGN.md Typography (headings 600 weight, line height 1.2; text width); DESIGN.md Accessibility (WCAG 2.2 AA, visible focus, keyboard use, `lang`); `style-guide.html` as the rendered reference
- **Architecture Traceability**: Content Store (CV entry), Site Build
- **Security Traceability**: SEC-OUT-1 (via REQ-OUTPUT-010)

## Acceptance Criteria

1. **AC-01 — Expected behavior**: Given published CV entries in all six sections, when the Site Build runs, then the CV page shows six sections in the order of FR-5.2, each with a heading and its entries in the page's language.
2. **AC-02 — Boundary or failure behavior**: Given a section with no published entry, when the CV page is generated, then the page renders without errors; whether an empty section heading is shown is not decided (PQ-23) and is not asserted.
3. **AC-03 — Prohibited behavior**: Given an unpublished CV entry, when the CV page is generated, then it does not appear.
