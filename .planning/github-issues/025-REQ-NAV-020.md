## Requirement

- **Statement**: The Site Build MUST generate every page in English and in German, the English version outside `/de/` (the site root `/` is the English home page) and the German version under `/de/`; every page MUST offer a language switch "DE | EN" in the header that opens the same page in the other language, with the current language marked and announced to screen readers; each page's `lang` attribute MUST match its language; the site MUST NOT redirect visitors based on their browser language.
- **Rationale**: The site serves international and German audiences equally (FR-1.2, FR-1.6).
- **Assumptions**: None
- **Out of Scope**: What shows when one language value is empty (REQ-NAV-030); main navigation (REQ-NAV-010).
- **Design Traceability**: DESIGN.md Components (Language switch); DESIGN.md Accessibility (WCAG 2.2 AA, visible focus, keyboard use, `lang`); `style-guide.html` as the rendered reference
- **Architecture Traceability**: Site Build (DE `/de/` and EN `/`, language switch targets); Public Site
- **Security Traceability**: SEC-OUT-5 (only if client-side code is added; none is needed)

## Acceptance Criteria

1. **AC-01 — Expected behavior**: Given the built site, when `/` is requested, then the English home page is served with `lang="en"`; when `/de/` is requested, the German home page is served with `lang="de"`.
2. **AC-02 — Expected behavior**: Given the English page of the work `tiptoe`, when the visitor activates "DE", then the German page of the same work opens, and vice versa.
3. **AC-03 — Boundary or failure behavior**: Given a request to `/` with `Accept-Language: de`, when it is served, then the English home page is returned with status 200 and no redirect.
4. **AC-04 — Prohibited behavior**: Given any page, when its German and English versions are compared, then the work title is identical in both (FR-1.5).
5. **AC-05 — Additional criterion**: Given a keyboard and screen reader user, when the language switch is reached, then both options are operable by keyboard and the current language is announced.
